# API Versioning Strategy

## Version 1 (Current)
- Base URL: `/api/v1`
- Stable REST endpoints.
- Fully backward compatible format mappings.

## Version 2 (Future)
- GraphQL transitions or breaking structural variations.
- Migration guides will accompany version rollouts.

## Deprecation Policy
- Version support continues for 6 months post-deprecation notices.
- Deprecation headers in response alerts.
