# User and Administrator Guide

This is an outline; add verified screenshots, routes, and actual behavior after frontend integration.

## User guide
Sign in/out; select organization; understand roles; connect cloud account; view assets/relationships; review scans/findings/evidence/risk; explore incidents/attack paths; read AI explanations and citations; request/approve/reject remediation; review verification/audit; export reports; troubleshoot.

## Administrator guide
Manage members/roles/invitations; configure provider access safely; configure runbooks/approval thresholds; monitor agent/queue/retry/DLQ health; review audit; configure retention/backups/restore; rotate credentials and respond to suspected compromise.

Never ask users to paste cloud secret keys into chat or issue trackers. Use the approved application credential-entry mechanism only after its security has been verified.
